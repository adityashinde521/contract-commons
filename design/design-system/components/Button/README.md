# Button

Buttons start or confirm one action. Use one primary button per view.

- **Primary** (`cc-btn cc-btn--primary`): the main action on a light ground.
- **Secondary** (`cc-btn cc-btn--secondary`): alternatives next to a primary.
- **Accent** (`cc-btn cc-btn--accent`): the main action on `brand-900` only.
- **Ghost dark** (`cc-btn cc-btn--ghost-dark`): secondary action on `brand-900`.
- Labels say what happens: "Start quiz", "Open lab log". Minimum height 44px.
