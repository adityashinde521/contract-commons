# Callout

Callouts set off a warning, a legal question, a real-world problem or a pointer to a tool.

- `cc-callout--warn`: rules that prevent errors (the Value rule, safety).
- `cc-callout--law`: legal text and questions for law students.
- `cc-callout--problem`: the question a lesson answers.
- `cc-callout--tool`: "See it in a real tool" links.
- One callout per idea; start with a bold lead-in.
