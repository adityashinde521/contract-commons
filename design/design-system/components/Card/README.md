# Card

Cards group one module, path, persona or lesson section. Flat, bordered, no shadow.

- Default `cc-card` (radius-lg) in grids; `cc-card--xl` for lesson sections; `cc-card--active` for the step the learner is on.
- Start with an icon tile in the discipline tint, then the title (h3) and one or two lines of `muted` text.
- A card that links is one `<a>`; never nest buttons inside it.
