# DisciplineTabs

> Not used on the course site since November 2026. The course now has one path for everyone, and the Apply step shows all three lenses (technology, business, law) side by side instead of tabs. Kept for reference.

Discipline tabs switch the Apply step between computer science, business informatics and law.

- Real `<button>` elements with `aria-pressed`; `data-d` = cs, bi or law sets the selected colour.
- Default to the learner's own discipline.
