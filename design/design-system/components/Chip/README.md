# Chip

Chips label a lesson's kind, discipline, duration or status.

- Neutral `cc-chip` for facts (60 min, Remix VM).
- Discipline: `cc-chip--cs`, `cc-chip--bi`, `cc-chip--law`.
- Status: `cc-chip--brand` (passed), `cc-chip--pending` (awaiting delivery), `cc-chip--warn` (sample data, in review).
- Keep to one or two words; never more than four chips in a row.
